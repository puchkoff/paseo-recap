Recap adds a Recap button to each agent's composer. Pressing it sends the prompt "tldr recap and next steps?" to that agent and opens a popup that shows the agent's answer when the turn ends, so you can catch up on a long chat in one tap.

The prompt and the answer also stay in the chat like any message you type. Closing the popup does not stop the agent; reopening it while the recap runs shows the same answer instead of asking again. There are no settings and no daemon code.
